# IVA – Computer Vision & Face Recognition

An interactive web-based assignment project for **Image and Video Analytics (IVA)** covering four important computer vision and face-recognition techniques:

- Template Matching
- Viola–Jones Algorithm
- DeepFace
- FaceNet

## 🌐 Live Demo

Deploy this project using **Vercel** or another static hosting platform.

## ✨ Features

### 1. Template Matching
Upload a main image and a template image to find the region that most closely matches the template.

### 2. Viola–Jones Face Detection
Upload an image and detect faces using the classical **Haar Cascade classifier** through OpenCV.js.

### 3. DeepFace
Explains the DeepFace pipeline and provides a browser-based feature visualization. Full DeepFace inference requires a trained deep-learning model and suitable runtime.

### 4. FaceNet
Demonstrates the concept of face embeddings and metric learning. Full FaceNet inference requires a trained FaceNet model/runtime.

### 🎨 Website Features

- Interactive topic sections
- Image upload functionality
- Template matching demonstration
- Face detection demonstration
- DeepFace feature visualization
- FaceNet embedding visualization
- Method comparison table
- Dark / light mode
- Responsive design for desktop and mobile
- References section

## 🚀 Run Locally

1. Download or clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/iva-computer-vision-assignment.git
```

2. Open the project folder.

```bash
cd iva-computer-vision-assignment
```

3. Open `index.html` in a browser.

For the best experience, use a local server such as VS Code Live Server.

## ☁️ Deploy with Vercel

1. Push the project to GitHub.
2. Open Vercel.
3. Import the GitHub repository.
4. Select **Other** as the framework preset.
5. Leave the build command empty.
6. Deploy.
